## 📦 项目

- **[dsh-secure-audit](https://github.com/PensiveFei/dsh-secure-audit)** — DeepSeek Harness 的只读安全审计插件：提示词注入检测、中文 PII 脱敏、本地配置审计，报告脱敏且可复现。
- **[dsh-voice-scribe](https://github.com/PensiveFei/dsh-voice-scribe)** — DSH 语音输入插件：按 Alt 说话，文字直接进入输入框；默认 Web Speech 零配置，可选 OpenAI 兼容 ASR。
- **[deep-read-summarize](https://github.com/PensiveFei/deep-read-summarize)** — 面向书籍、论文、视频和网页的深度精读与总结工作流，MapReduce 深读，输出适配 Obsidian。
- **[prompt-security-kit](https://github.com/PensiveFei/prompt-security-kit)** — 轻量、中文优先的提示词注入检测与 PII 脱敏 SDK，适用于 Agent 数据流（LangChain.js / MCP），零依赖、可离线运行。
